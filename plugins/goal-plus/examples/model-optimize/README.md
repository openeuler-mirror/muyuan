# Model Optimize Example

The runnable example is [`torch-cpu-target/`](torch-cpu-target/). It contains a
deterministic single-core PyTorch workload, correctness verifier, throughput
benchmark, and ready-to-paste prompts for both Codex and Pi.

Start in that directory and follow its README. Goal Plus discovers and freezes
the Search contract from the current workspace; no checked-in SearchSpec is
required for a normal run.
