怎么工作

让模型直接编题，会稳定产出送分题。本模块改用反向构造： 从真实会话重放文件修改前 / 后两个版本，以前者为 stub、后者为参考解， 模型只写能区分两版的测试与现象态题面。再用锚点面板校准，留下有区分度的题， 供后续消融比较 Agent 与模型。

逐步命令见仓库内 docs/USER_GUIDE.md。CLI 与配置字段见 docs/REFERENCE.md。
